# 🎬 Portal Web Studio Ghibli - Consumo de API REST

Este proyecto es una aplicación web frontend desarrollada para la asignatura **Diseño de Sistemas en Internet**. La aplicación consume datos en tiempo real desde una API pública externa y los presenta mediante tarjetas interactivas y un buscador en tiempo real.

## 📌 Objetivo de la Tarea
- Desarrollar un portal web interactivo consumiendo un servicio web público (API REST).
- Implementar peticiones asíncronas con JavaScript moderno (`fetch` y `async/await`).
- Renderizar de forma dinámica elementos en el DOM con estilos responsivos y accesibles.

## 🚀 API Consumida
- **API**: Studio Ghibli Public API
- **Endpoint**: `https://ghibliapi.vercel.app/films`
- **Datos obtenidos**: Títulos en inglés y japonés, año de lanzamiento, puntaje Rotten Tomatoes, directores, sinopsis e imágenes de portada.

## 🛠️ Tecnologías Utilizadas
- **HTML5**: Estructura semántica (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3**: Diseño responsivo con CSS Grid y Flexbox, variables CSS y paleta estética moderna.
- **JavaScript (ES6+)**: Peticiones asíncronas (`fetch`, `async/await`), manejo de promesas, filtrado de datos en memoria y manipulación dinámica del DOM.
- **Git & GitHub**: Control de versiones y alojamiento del código fuente.
